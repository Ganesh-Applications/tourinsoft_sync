== Description ==

Synchronisation des données Tourinsoft avec WordPress.

Voir README.md pour la documentation complète.

= Prérequis =

* WordPress 6.5 ou plus
* PHP 7.4 ou plus
* Advanced Custom Fields PRO 6.1 ou plus. Les post types à synchroniser doivent être créés depuis ACF (menu « ACF → Post Types »), car c'est là que se règle le flux Tourinsoft.

== Installation ==

1. Copier le dossier dans `wp-content/plugins/`.
2. Activer Advanced Custom Fields PRO, s'il ne l'est pas déjà.
3. Activer le plugin depuis le menu « Extensions ».
